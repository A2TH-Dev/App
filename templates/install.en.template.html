How to Install an APK

Apps on {{SITE_BRAND}} are distributed directly as APK files via GitHub Releases — not through the Play Store. Android will show a standard warning when installing from outside the Play Store. That's normal, not a sign the APK is unsafe.

1

Allow installs from unknown sources

When you open the downloaded APK, Android usually shows a warning like "For your security, your phone is not allowed to install unknown apps from this source." Tap Settings in that notification, then enable "Allow from this source" for whichever browser or file manager you used. This is a per-app setting, safe, and can be turned off again anytime.

2

Open the APK file again

Once the permission is enabled, reopen the APK file from your download notification or your Downloads folder in the File Manager. Tap Install.

3

(Optional) Play Protect scan

Google Play Protect may offer to scan the APK before installing. This is a built-in Android security feature, not something specific to {{SITE_BRAND}} — you can run it for extra peace of mind, or skip straight to installing if you already trust the source.
