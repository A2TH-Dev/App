Cara Install APK

Aplikasi di {{SITE_BRAND}} dibagikan langsung sebagai file APK lewat GitHub Releases — bukan dari Play Store. Android akan menampilkan peringatan standar saat install dari luar Play Store. Ini normal, bukan tanda APK-nya berbahaya.

1

Izinkan install dari sumber tak dikenal

Pas buka file APK yang baru di-download, Android biasanya munculin peringatan "Untuk keamanan HP, sumber ini diblokir". Ketuk Pengaturan di notifikasi itu, lalu aktifkan "Izinkan dari sumber ini" untuk browser/file manager yang kamu pakai. Ini pengaturan per-aplikasi, aman, dan bisa dimatikan lagi kapan saja.

2

Buka lagi file APK-nya

Setelah izin diaktifkan, buka ulang file APK dari notifikasi download atau folder Download di File Manager. Ketuk Install.

3

(Opsional) Play Protect scan

Kadang Google Play Protect nawarin scan APK sebelum install. Ini fitur keamanan bawaan Android, bukan khusus buat APK dari {{SITE_BRAND}} — boleh dijalankan buat ketenangan tambahan, atau langsung lanjut install kalau sumbernya sudah kamu percaya.
