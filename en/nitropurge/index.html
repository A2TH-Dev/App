  • 🔒 Added App Lock with brute-force protection (salted SHA-256, tiered backoff)
  • 🔧 Fixed a race condition in AppLockRepository when the PIN is checked simultaneously from the UI + accessibility service
  • 🐛 Fixed a crash when scanning large files – added timeout handling in StorageGrowthPredictor with fallback
  • 🐛 Fixed DuplicateContactScanner – corrected merge logic so contact numbers aren't lost, skips contacts with no name
  • 🐛 Fixed OneTapCleanQuota – cleared a not-yet-loaded aggressiveness threshold at app startup
  • 🐛 Fixed the native result parser – unified delimiter handling across ApkInspector, VideoScanner, LargeFileScanner
  • 🐛 Fixed AppPatternMatcher – ensured a consistent Kotlin fallback when native load fails
  • 📊 Improved error handling in PhotoCompressor (quality detection + invalid EXIF), NitroPurgeApp (WorkManager init), TurboMonitorViewModel (polling job cancellation)

  • 🔐 Hardened NitroPurgeApp init + improved error logging for easier diagnostics
  • ✅ Thoroughly verified ~3,400 lines of native-lib.cpp (24 JNI functions) – filesystem walk, duplicate finder, DCT perceptual hash, APK parser, fuzzy clustering, linear regression
