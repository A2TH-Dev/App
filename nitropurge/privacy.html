Kebijakan Privasi

Nitro Purge Terakhir diperbarui: 2026-07-26

Pembersih & optimizer Android tanpa drama.

Nitro Purge ("aplikasi ini") dikembangkan oleh Tri Nofri Andi (A2TH-Dev) ("kami"). Kebijakan Privasi ini menjelaskan bagaimana aplikasi mengakses, menggunakan, dan melindungi data pada perangkat Android kamu.

shield_with_heart

Prinsip Utama

Semua pemrosesan data di Nitro Purge terjadi secara lokal di perangkat kamu. Kami tidak mengoperasikan server backend, tidak mengunggah file, foto, kontak, atau data penggunaan aplikasi kamu ke internet, dan tidak menjual data kamu ke pihak ketiga.

Izin yang Digunakan & Alasannya

  • Akses Semua File (MANAGE_EXTERNAL_STORAGE) — dipakai untuk memindai dan menghapus file sampah, cache, file besar, file duplikat, foto mirip, video, serta folder sisa aplikasi yang sudah di-uninstall. File hanya diproses di perangkat; tidak ada file yang dikirim keluar perangkat.
  • Akses Penggunaan Aplikasi (PACKAGE_USAGE_STATS) — dipakai untuk fitur Screen Time / Usage Insights dan App Manager, agar aplikasi bisa menampilkan durasi pemakaian dan ukuran cache tiap app. Data ini hanya dibaca dan ditampilkan di layar, tidak disimpan di luar perangkat.
  • Kontak (READ_CONTACTS / WRITE_CONTACTS) — dipakai khusus untuk fitur Kontak Duplikat, untuk mendeteksi dan (atas persetujuan kamu) menggabungkan entri kontak yang sama. Data kontak tidak pernah meninggalkan perangkat.
  • Akses Notifikasi (Notification Listener Service) — dipakai khusus untuk fitur Notification Cleaner, agar kamu bisa membersihkan semua notifikasi aktif dalam satu tap. Aplikasi tidak membaca, menyimpan, atau mengirim isi notifikasi kamu ke pihak manapun.
  • Biometrik (USE_BIOMETRIC) — dipakai untuk fitur App Lock / Privacy Guard, agar kamu bisa mengunci aplikasi pilihan dengan sidik jari atau PIN. Data biometrik diproses oleh sistem Android itu sendiri; aplikasi ini tidak pernah menyimpan atau memiliki akses ke data sidik jari kamu.
  • Notifikasi (POST_NOTIFICATIONS) — dipakai untuk menampilkan notifikasi terkait pembersihan otomatis terjadwal (Auto Clean).

Root Mode (jika tersedia di perangkatmu)

Fitur Root Mode hanya muncul jika aplikasi mendeteksi perangkat kamu sudah di-root, dan sepenuhnya opsional. Fitur ini menjalankan perintah sistem (force-stop, clear cache) atas permintaan eksplisit kamu di perangkat kamu sendiri — tidak ada data yang dikirim keluar perangkat melalui fitur ini.

Data yang TIDAK Kami Kumpulkan

  • Kami tidak mengumpulkan nama, email, atau identitas pribadi kamu.
  • Kami tidak melacak lokasi kamu.
  • Kami tidak membuat profil iklan berdasarkan perilaku kamu di luar aplikasi ini.

Iklan

Versi gratis (Free) Nitro Purge dapat menampilkan iklan melalui Google AdMob. SDK iklan pihak ketiga ini dapat mengumpulkan pengenal perangkat (advertising ID) sesuai dengan kebijakan privasi masing-masing penyedia. Kamu bisa membaca kebijakan privasi penyedia iklan di: https://policies.google.com/technologies/ads. Versi berbayar (Pro) Nitro Purge sama sekali tidak menampilkan iklan dan tidak memiliki izin akses internet.

Keamanan Data

Karena seluruh pemrosesan dilakukan secara lokal, risiko kebocoran data terbatas pada keamanan perangkat Android kamu sendiri. Kami menyarankan mengaktifkan kunci layar dan menjaga sistem operasi tetap ter-update.

Perubahan Kebijakan Ini

Kebijakan ini dapat diperbarui sewaktu-waktu mengikuti perubahan fitur aplikasi atau ketentuan Google Play. Perubahan akan tercermin pada tanggal "Terakhir diperbarui" di atas.
