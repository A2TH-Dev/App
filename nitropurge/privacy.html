Kebijakan Privasi

Nitro Purge Terakhir diperbarui: 2026-08-06

Pembersih & optimizer Android tanpa drama.

NitroPurge membersihkan file sampah, mengubah ukuran foto, menghapus duplikat kontak, dan mengunci aplikasi sensitif dengan PIN — semua dari satu dashboard ringan tanpa iklan mengganggu.

shield_with_heart

01 Data yang Dikumpulkan

Nitro Purge dibangun dengan prinsip local-first. Aplikasi ini tidak memiliki server backend, sehingga tidak ada file, foto, kontak, atau data pemakaian yang pernah diunggah ke internet. Data berikut diakses secara lokal di perangkat kamu untuk menjalankan fitur yang kamu pilih:

  • File & media (untuk Junk Cleaner, Large File Finder, Duplicate Finder, Photo Compressor, Video Cleaner, App Leftover Finder)
  • Statistik penggunaan aplikasi (untuk Usage Insights / Screen Time dan App Manager)
  • Kontak (khusus fitur Duplicate Contacts)
  • Notifikasi aktif (khusus fitur Notification Cleaner — isi notifikasi tidak dibaca untuk tujuan lain)
  • Data biometrik untuk App Lock ditangani sepenuhnya oleh sistem Android (BiometricPrompt); Nitro Purge sendiri tidak pernah menyimpan data biometrik apapun
  • Advertising ID / Device ID — khusus edisi Free, dipakai oleh Google Mobile Ads SDK untuk menampilkan iklan (lihat bagian 03)

Edisi Pro tidak memiliki izin internet sama sekali secara teknis, sehingga tidak ada data yang bisa keluar dari perangkat dalam bentuk apapun — bisa diverifikasi lewat menu "Sertifikat Privasi" di dalam aplikasi.

02 Bagaimana Data Digunakan

Seluruh data pada bagian 01 diproses hanya di perangkat kamu, semata-mata untuk menjalankan fitur pembersihan, analisis penyimpanan, atau keamanan yang kamu buka secara langsung. Nitro Purge tidak membangun profil pengguna, tidak menjual data, dan tidak menggunakan data tersebut untuk tujuan lain di luar fitur yang bersangkutan. Satu-satunya pengecualian adalah edisi Free, di mana Advertising ID/Device ID dipakai oleh Google Mobile Ads SDK untuk menampilkan iklan banner, interstitial, dan rewarded — dijelaskan lebih lanjut di bagian 03.

03 Berbagi Data ke Pihak Ketiga

Edisi Pro: tidak membagikan data apapun ke pihak manapun — aplikasi ini secara teknis tidak memiliki izin internet, sehingga tidak ada koneksi jaringan yang bisa dibuka sama sekali.

Edisi Free: menggunakan Google Mobile Ads SDK (AdMob) dan Google User Messaging Platform (UMP) untuk menampilkan iklan dan mengelola persetujuan privasi pengguna di Uni Eropa/Inggris (GDPR/UK). Lewat SDK ini, Advertising ID dan Device/other ID dikirim ke Google untuk keperluan penayangan iklan. Kamu bisa meninjau atau mencabut persetujuan ini kapan saja lewat Pengaturan → Preferensi Iklan di dalam aplikasi. Kebijakan privasi Google dapat dibaca di policies.google.com/privacy dan kebijakan mitra iklan Google di policies.google.com/technologies/partner-sites.

Di luar hal tersebut, tidak ada data lain (file, kontak, statistik pemakaian, dsb.) yang dibagikan ke pihak ketiga manapun oleh Nitro Purge.

Edisi Pro tidak mendeklarasikan izin internet maupun Advertising ID sama sekali. Root Mode tidak membutuhkan izin Android apapun — fitur ini murni opsional, hanya muncul jika perangkat sudah di-root, dan aksi yang bisa dijalankan dibatasi ke daftar tetap (force-stop & bersihkan cache app), bukan perintah shell bebas.
