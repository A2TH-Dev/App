Kebijakan Privasi

Peta Jiwa Terakhir diperbarui: 2026-08-05

Peta kepribadian dan arah hidupmu.

Peta Jiwa adalah alat analisis diri lengkap: natal chart & Human Design dari tanggal-jam-lokasi lahir, tes kepribadian 5 sifat utama, analisis wajah & sidik jari, cek kecocokan dua orang, jurnal harian dengan mood tracker, hingga fokus Pomodoro dengan melodi penenang — semua tersimpan lokal di HP tanpa perlu koneksi internet.

shield_with_heart

01 Data yang Dikumpulkan

Peta Jiwa dibangun dengan prinsip local-first. Aplikasi ini tidak memiliki server backend, sehingga tidak ada data pribadi yang pernah diunggah ke internet. Data berikut diakses untuk menjalankan fitur di dalam aplikasi:

  • Data lokasi (perkiraan & presisi) — untuk menghitung natal chart (peta astrologi kelahiran) berdasarkan koordinat tempat lahir atau lokasi kamu saat ini; diproses hanya di perangkat (on-device) dan tidak pernah dikirim ke server manapun
  • Nama dan tanggal lahir — untuk fitur analisis numerologi/astrologi, disimpan hanya secara lokal di perangkat
  • Foto wajah (opsional) — untuk fitur analisis tertentu, disimpan hanya secara lokal di perangkat
  • Catatan/entri jurnal pribadi — disimpan hanya secara lokal di perangkat
  • Advertising ID — dipakai oleh Google AdMob untuk menampilkan iklan (interstitial & rewarded video) serta personalisasi dan pengukuran performa iklan

Kami tidak mengoperasikan server backend untuk aplikasi ini. Nama, tanggal lahir, foto, dan jurnal hanya tersimpan di penyimpanan internal perangkat kamu. Jika aplikasi dihapus atau data aplikasi dibersihkan, data ini hilang secara permanen dan tidak dapat kami pulihkan.

02 Bagaimana Data Digunakan

Data pada bagian 01 digunakan semata-mata untuk menjalankan fitur inti aplikasi (perhitungan natal chart, analisis numerologi/astrologi, jurnal pribadi), menampilkan iklan melalui AdMob, dan meningkatkan stabilitas serta pengalaman pengguna. Kami tidak menggunakan data pribadi (nama, tanggal lahir, foto, jurnal) untuk tujuan apapun di luar aplikasi, karena data tersebut tidak pernah meninggalkan perangkat kamu.

03 Berbagi Data ke Pihak Ketiga

Kami tidak menjual, menyewakan, atau membagikan data pribadi kepada pihak ketiga di luar keperluan menampilkan iklan.

Aplikasi menggunakan Google AdMob dan Google User Messaging Platform (UMP) untuk menampilkan iklan dan mengelola persetujuan iklan, termasuk untuk pengguna di wilayah EEA/UK (GDPR/UK). Lewat SDK ini, Advertising ID dapat dikumpulkan oleh Google untuk keperluan personalisasi dan pengukuran performa iklan, tunduk pada policies.google.com/privacy.

Data lokasi, nama, tanggal lahir, foto wajah, dan jurnal tidak pernah dikirim, diunggah, atau disimpan di server kami maupun pihak ketiga manapun.
